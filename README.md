# Tic Tac Toe Master

A simple, clean, and responsive **Tic Tac Toe game** built with HTML, CSS, and JavaScript.

Play directly in your browser without installing anything.

## Play Now

**[Play Tic Tac Toe Master](https://tarunshukla11.github.io/Tic-Tac-Toe/)**

## Features

* Classic 3×3 Tic Tac Toe gameplay
* Two-player local gameplay
* Player X and Player O turns
* Automatic winner detection
* Draw/tie detection
* Score tracking
* Winning-cell animation
* Restart game option
* Play-again popup
* Responsive design
* Works on desktop and mobile browsers
* No installation required for the web version

## How to Play

1. Open the game using the **Play Now** link.
2. Player X starts the game.
3. Players take turns selecting an empty cell.
4. Get three of your symbols in a row to win.
5. The first player to complete a row, column, or diagonal wins.
6. If all cells are filled without a winner, the game ends in a draw.
7. Use **Restart** to start a new round.

## Winning Combinations

There are 8 possible winning combinations:

```text
Rows
X | X | X
---------
  |   |
---------
  |   |

Columns
X |   |
X |   |
X |   |

Diagonals
X |   |
  | X |
  |   | X
```
